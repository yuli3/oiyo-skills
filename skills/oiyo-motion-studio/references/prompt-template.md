# 프롬프트 틀

## 공통 규칙 (모든 모션 앞에 붙임)

```
HTML 파일 한 장으로 모션을 만들어 줘. 지킬 규칙:
1. 화면은 시간 t(초)의 순수 함수 render(t)로 그린다. 상태를 쌓지 않는다. 같은 t에는 언제나 같은 그림이 나와야 한다.
2. transform과 opacity만 움직인다. width·top 같은 배치 속성은 애니메이션하지 않는다.
3. 타이밍은 구간 진행도 sg(t, a, b) = clamp((t-a)/(b-a))에 곡선을 씌워 적는다. 등장은 ease-out, 장면 전환은 ease-in-out. 0에서 커지는 scale(0)은 쓰지 않는다.
4. 고정 크기 무대 <div id="s">에 그리고, 마지막에 window.MOTION = { w, h, dur, poster, render }를 내보낸다. 재생·화면 맞춤·영상 렌더는 stage.js가 맡는다.
5. 한국어는 word-break: keep-all, 숫자는 font-variant-numeric: tabular-nums.
```

## 장면 시간표 쓰는 법

```
{가로}×{세로} {세로/정사각}, {N}초 {광고/반복 모션}을 만들어 줘. 주제는 {한 줄}.
- 0~{a}초: {첫 장면. 무엇이 어디서 어떻게 나타나는지}
- {a}~{b}초: {본 장면. 반복 단위가 있으면 몇 초씩 몇 번}
- {b}초~: {마무리. 로고·주소}
{색·글꼴·분위기 한 줄}
```

느낌 대신 숫자를 적어요. "천천히" 대신 "14초 동안 scale 1.02 → 1.18", "차례로" 대신 "0.18초 간격". 화면에 들어갈 문구는 따옴표로 정확히 적어요. 실제 데이터처럼 보이는 숫자는 예시라고 밝히거나 넣지 않아요.
